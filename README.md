# quiz-app2 - AV女優クイズ

ブラウザで遊べる、全5問・4択のAV女優クイズアプリです。

## 特徴

- 回答するとすぐに正解・不正解と解説を表示
- 最後に「5問中◯問正解」の形でスコアを表示
- 不正解時と結果画面に、ちょっとうざい煽りコメント付き

## 遊び方

- **オンライン:** GitHub Pages で公開した URL にアクセス
- **ローカル:** `index.html` をブラウザで開く

## 技術スタック

HTML / CSS / JavaScript（ライブラリ・ビルドツール不使用）

## ファイル構成

```
quiz-app2/
├── index.html   # 画面の構造
├── style.css    # スタイル
└── script.js    # 問題データとクイズの進行ロジック
```
